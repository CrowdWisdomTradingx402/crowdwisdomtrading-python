# Privacy Policy

Last updated: November 24, 2026

This plugin is published by Tsuroni LTD, the company behind CrowdWisdom Trading.

## What the plugin sends

Each tool call sends one HTTPS GET request to the fixed host
`api.crowdwisdomtrading.com`. The only user input in that request is the ticker
symbol (for example `AAPL`), which is part of the URL. The plugin needs no API
key, account, name or email, and it sends no conversation text, files or other
data from your Dify workspace.

## What our server sees and logs

Like any web server, the CrowdWisdom Trading API sees the IP address the request
comes from (your Dify server or Dify Cloud) and the request's user agent. For
each request it logs the IP address, user agent, requested route (which contains
the ticker) and time. We use this to deliver the response, enforce the free limit
of 50 calls a day per IP address, prevent abuse and keep service records.

## What the plugin itself collects

The plugin does not collect, store or log any user data of its own. It does not
write files, run code, place orders or contact any other URL. It does not share
data with third parties.
